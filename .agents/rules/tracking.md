# Progress Tracking Rules

1. **Living Document**: The file `PROGRESS.md` at the root of the project is the definitive tracker of what has been built and what is left to do.
2. **When to Update**:
   - Whenever you complete a meaningful sub-task or phase, you MUST check off the corresponding item in `PROGRESS.md` by changing `[ ]` to `[x]`.
   - Whenever the scope expands or requirements change, you MUST add new tasks to `PROGRESS.md`.
3. **How to Update**:
   - Modify checkboxes or add tasks directly in `PROGRESS.md`.
   - Never skip updating the tracker when you finish an important chunk of code (e.g., finishing an Entity, a Use Case, or a Controller).
4. **Visibility**: Always inform the user what tasks you have checked off after you update `PROGRESS.md`.
